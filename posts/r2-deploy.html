Cloudflare R2 部署手册

📅 发布日期: 2026.04.11 🏷 标签: 云端存储 / 后端架构 ⏱ 阅读用时: ~4 分钟

Cloudflare R2 是免出站流量费（Zero Egress Fees）的高性能 S3 兼容对象存储服务。在工业自动化与边缘计算实践中，它是存放海量现场数据日志、CAD 图纸固件以及设备数字快照的最佳载体。

1. 存储桶创建与权限隔离

登录 Cloudflare Dashboard，在侧边栏选择 R2 对象存储。创建 Bucket 并命名为 jinyi-storage。出于工业控制与内部资产安全考虑，强烈建议保持默认的非公开状态，通过 Cloudflare Workers 或带签名认证的授权链路进行读写控制。

2. CORS 跨域规则配置

⚠️ 关键配置提示：前端通过浏览器 JS 发起直接文件上传/下载时，必须在 R2 存储桶配置 CORS 规则，否则请求将被浏览器同源策略拦截。
[
  {
    "AllowedOrigins": [
      "https://www.jinyi.eu.org",
      "https://my-website.pages.dev"
    ],
    "AllowedMethods": [
      "GET",
      "PUT",
      "POST",
      "HEAD"
    ],
    "AllowedHeaders": [
      "Content-Type",
      "X-Custom-Auth"
    ],
    "MaxAgeSeconds": 3600
  }
]

3. 成本控制与数据生命周期策略

Cloudflare R2 每月提供 10 GB 免费存储空间 及充足的免 Class A/B 操作额度。建议在 Bucket 管理页面的 Lifecycle Rules 中设定自动化归档与过期清理规则，例如对临时遥测日志（/logs/temp/*）配置自动清除，实现“零维护、零成本”的自动化数据生命周期管理。
