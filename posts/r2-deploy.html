Cloudflare R2 部署手册

发布日期: 2026.04.11 | 标签: 云端存储, 后端技术

Cloudflare R2 是一个免流量费的对象存储服务。对于机械与自动化工程师来说，它是存放大型日志、CAD 图纸和固件备份的理想选择。

1. 存储桶配置

首先在 Cloudflare 后台创建一个 Bucket，并命名为 jinyi-storage。为了确保安全，我们不建议开启公开访问。

2. CORS 跨域策略

注意：如果不配置 CORS，你的网页前端将无法通过 JS 直接上传文件到 R2。
[
  {
    "AllowedOrigins": ["https://www.jinyi.eu.org"],
    "AllowedMethods": ["GET", "PUT", "POST"],
    "AllowedHeaders": ["Content-Type", "X-Custom-Auth"]
  }
]

3. 费用控制

R2 的免费额度为 10GB。建议在 R2 设置中开启生命周期规则，自动删除 30 天前的临时日志文件，以确保存储空间不超限。
